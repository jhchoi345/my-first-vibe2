## 확정 정보
- **서비스 이름:** 모먼트립 (Momentrip)
- **한 줄 무드:** 지난 여행의 순간에 다시 설레고, 다음 여행을 기대하게 만드는 밝고 다정한 여행 메이트

## 1. Voice Summary
여행 가기 전부터 들떠 있고 다녀와서도 "다음엔 어디 갈까?" 하는 설레는 여행 메이트처럼 말해요. 내 추억에 같이 신나 하지만, 고르고 쓰는 건 언제나 나에게 맡겨요.

## 2. Core Personality Traits

**설레는**
- We are: 여행과 추억 앞에서 진심으로 들뜬 마음을 짧고 밝게 전해요.
- We are not: 느낌표와 이모지를 쏟아내는 호들갑.
- This sounds like: "오사카 여행 잘 다녀왔어요? 🎉 그 순간들, 사진으로 다시 꺼내 볼까요?"
- This does NOT sound like: "🎉🎉 오사카 여행 완료!!! 사진 올리고 인생 영상 만들어 봐요!!! 🔥"

**다정한**
- We are: 친구처럼 먼저 반기고, 부담 없이 시작하게 손을 내밀어요.
- We are not: 왜 안 했냐고 챙기고 캐묻는 오지랖.
- This sounds like: "아직 마그넷이 없네요. 첫 여행을 붙여 볼까요? 지난 여행도 좋아요 🧳"
- This does NOT sound like: "오늘 사진 왜 안 올렸어요? 여행 잘 다니고 있는 거죠? 😢"

**유쾌한**
- We are: 가볍고 밝은 말로 기록하는 시간을 즐겁게 만들어요.
- We are not: 돈이나 추억을 놀림거리로 삼는 장난.
- This sounds like: "완성! 그때 그 장면들, 노래랑 같이 다시 떠나 볼까요? ✨"
- This does NOT sound like: "ㅋㅋㅋ 돈 엄청 썼네요?? 텅장 축하드려요~"

**센스 있는**
- We are: 비슷한 사진을 묶어 주고 영상을 엮어 주며 슬쩍 도와요.
- We are not: 내 취향을 대신 판단하는 잘난 척.
- This sounds like: "같은 곳에서 찍은 사진끼리 모아 뒀어요. 제일 마음에 드는 한 장을 골라 주세요."
- This does NOT sound like: "이 사진은 구도가 별로라 빼 드렸어요. 이게 더 낫죠?"

**함께하는**
- We are: 여행의 처음부터 끝까지 옆에 있지만, 기록의 주인은 나라는 걸 지켜요.
- We are not: 내가 쓴 한 줄을 고쳐 주겠다며 끼어드는 것.
- This sounds like: "남겨 둔 한 줄이 이 사진이랑 같이 보여요."
- This does NOT sound like: "이 한 줄, 이렇게 바꿔 쓰는 게 더 감성적일 것 같아요!"

## 4. Vocabulary Guide

**USE**
| 표현 | 언제 · 왜 |
|------|-----------|
| 순간 | 모먼트립의 핵심 단어. 사진·한 줄·영상을 부를 때 |
| 잘 다녀왔어요? | 여행이 끝난 뒤 첫 인사. 친구처럼 먼저 반기기 |
| 다시 꺼내 볼까요? | 지난 여행을 열어 보게 할 때 |
| 다시 떠나 볼까요? | 영상·지도로 추억을 되짚을 때 |
| ~해 볼까요? / ~해 봐요 | 다음 행동을 권할 때. 명령 대신 제안 |
| 붙이다 / 붙여 볼까요? | 여행을 보드에 마그넷으로 더할 때 |
| 모으다 / 모아 뒀어요 | 비슷한 사진·추억을 정리해 줄 때 |
| 골라 주세요 / 마음에 드는 | 선택을 사용자에게 맡길 때 |
| 그때 그 장면 | 추억을 떠올리게 할 때 |
| 다음엔 어디 갈까요? | 다음 여행을 기대하게 할 때 |
| 이번 여행엔 이렇게 썼어요 | 경비를 담담하게 보여 줄 때 |
| 올리기 / 고르기 | 업로드·큐레이션 대신 쉬운 우리말 |
| 완성! | 영상·기록이 끝났을 때 짧은 축하 |
| 지난 여행도 좋아요 | 처음 시작하는 사람의 부담을 덜 때 |

**AVOID**
| 표현 | 왜 피하나 |
|------|-----------|
| 지금 정리하세요 / 미루면 영영 못 해요 | 기록을 숙제로 만드는 재촉 |
| 아직 정리 안 한 사진 N장 | 남은 양으로 압박하기 |

## 5. Tone Adaptation Rules

설렘·다정함은 늘 유지하고, 맥락에 따라 설렘의 크기만 조절한다. 경비·에러 안내에서는 설렘을 낮추고 다정함을 올린다.

**By Context (앱 안 맥락):**

| 맥락 | 톤 조절 | 예시 문구 |
|------|---------|-----------|
| 온보딩 / 첫 화면 | 설렘 중간, 다정함 높게. 부담 없이 시작하게 | "다녀온 여행의 순간들, 여기에 하나씩 모아 볼까요?" |
| 빈 상태(empty state) | 다정함 높게. 지난 여행도 괜찮다고 알려 주기 | "아직 마그넷이 없네요. 첫 여행을 붙여 볼까요? 지난 여행도 좋아요 🧳" |
| 성공/완료 피드백 | 설렘 가장 높게. 짧은 축하 + 다시 떠나 보자는 제안 | "완성! 그때 그 장면들, 노래랑 같이 다시 떠나 볼까요? ✨" |
| 에러/안내 | 설렘 낮게, 다정함 높게. 이모지 없이 차분하게 해결책 먼저 | "사진을 불러오지 못했어요. 잠시 후 다시 올려 볼까요?" |
| 경비 정리 | 담담하게. 평가 없이 사실만, 이모지 없이 | "이번 여행엔 이렇게 썼어요. 숙소가 가장 컸네요." |
| 푸시 알림 | 설렘 중간. 반기기 + 가벼운 제안, 재촉 금지 | "오사카 여행 잘 다녀왔어요? 🎉 그 순간들, 사진으로 다시 꺼내 볼까요?" |
| 랜딩/소개 페이지 | 설렘 높게. 지난 추억과 다음 여행을 함께 기대하게 | "다녀와서 사진만 올리면, 여행의 순간들이 영상이 돼요. 다음엔 어디 갈까요?" |

## 6. Style Rules
- 존댓말/반말: 존댓말 "~해요"체 기본. "~하세요" 같은 명령형보다 "~할까요?", "~해 봐요"처럼 권하기
- 문장 길이: 짧고 밝게. 한 문구는 1~2문장
- 이모지: 한 문구에 최대 1개. 설렘을 더할 때만 쓰고, 에러·경비 안내에는 쓰지 않기
- 느낌표: 한 문구에 최대 1개
- 경비 표현: "초과", "절약" 대신 "이번 여행엔 이렇게 썼어요"처럼 담담하게
- 외래어: "업로드", "큐레이션"보다 "올리기", "고르기"처럼 쉬운 우리말 먼저. 단 "모먼트립", "마그넷"은 그대로
- 쉬운 말: 처음 쓰는 사람도 바로 알아듣게

## 7. Do's and Don'ts

**Do:**
- 여행이 끝나면 "잘 다녀왔어요?"처럼 친구처럼 먼저 반겨요.
- 지난 여행을 다시 꺼내 보게 하고, 다음 여행까지 기대하게 해요.
- 다음 행동은 "~해 볼까요?"처럼 제안으로 권해요.
- 사진·영상은 도와서 모아 주되, 고르는 건 사용자에게 맡겨요.
- 주말 국내 여행도 해외 여행만큼 소중하게 다뤄요.
- 경비는 평가 없이 담담하게 보여 줘요.
- 영상이 완성되면 확실하게, 하지만 짧게 축하해요.

**Don't:**
- 기록을 숙제처럼 재촉하지 않아요. ("미루면 영영 못 해요")
- 경비로 죄책감을 주지 않아요. ("예산을 초과했어요. 절약하세요")
- 돈이나 추억을 놀리지 않아요. ("텅장 축하드려요~")
- 사진을 멋대로 빼거나 내 취향을 대신 판단하지 않아요.
- 사용자가 쓴 한 줄을 고쳐 쓰자고 끼어들지 않아요.
- 느낌표·이모지를 쏟아내는 호들갑이나 무거운 감성 에세이 톤을 쓰지 않아요.
- 세일즈·인플루언서·가이드북·프로 모험가·가계부·"AI가 다 해 드려요" 톤을 따라가지 않아요.
