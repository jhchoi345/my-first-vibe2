> 목표: 헤더로 화면이 나뉘고, 아래 탭으로 보드·지도·사진·내 계정에 갈 수 있다 · 관련 플로우: F1, F6, 기본 장치 · 조각 3개
> 정해둔 것: ../SETUP.md · 기획: FLOWS.md "앱 틀"

- [x] **1. 위 헤더 + 아래 탭바 + 내 계정** (앱 틀)
  - 확인: 보드 맨 위에 흰 헤더와 "모먼트립"이 보이고, 아래에 보드·지도·사진·내 계정 탭이 있다. 지금 탭은 주요 색이다
  - 확인: [지도]·[사진] 탭을 누르면 "준비하고 있어요" 안내가 보인다
  - 확인: [내 계정] 탭에서 [로그아웃]을 누르면 시작 화면이 나온다
- [x] **2. 안쪽 화면 헤더 통일** (앱 틀)
  - 확인: 여행 상세·여행 만들기·베스트 고르기에서 흰 헤더에 ← 와 제목이 보이고, 아래 탭바는 보이지 않는다
  - 확인: 여행 상세 헤더 오른쪽 ⋯ 메뉴가 그대로 열린다
- [x] **3. 보드 대표 사진 배너** (앱 틀)
  - 확인: 마그넷이 붙은 여행이 있으면 보드 맨 위에 가장 최근 여행의 대표 사진과 "{도시} 여행 잘 다녀왔어요?"가 보이고, 누르면 그 여행 상세로 간다
  - 확인: 빈 보드에는 배너가 없다
