# 01 · F1 첫 마그넷 붙이기

> Vibe Studio · build-spec · 작성일: 2026-10-16
> 목표: UI 구현 · 관련 플로우: F1 · 조각 4개
> 정해둔 것: ../SETUP.md

- [x] **1. 프로젝트 준비 + 시작 → 빈 보드** (F1 ①②)
  - 확인: 첫 화면에 "다녀온 여행의 순간들, 여기에 하나씩 모아 볼까요?"와 카카오·구글 버튼이 보인다
  - 확인: [카카오로 시작하기]를 누르면 "아직 마그넷이 없네요. 첫 여행을 붙여 볼까요? 지난 여행도 좋아요 🧳"가 있는 빈 보드가 나온다
  - 확인: 새로고침해도 시작 화면으로 돌아가지 않고 보드가 그대로 보인다
- [x] **2. 여행 만들기** (F1 ③)
  - 확인: [여행 붙이기]를 누르면 도시·날짜 입력 화면이 나오고, 예산 칸은 없다
  - 확인: 도시를 비우고 [사진 올리기]를 누르면 "어디로 다녀왔는지 알려 주세요"가 보인다
  - 확인: 앞으로의 날짜를 넣으면 "아직 안 간 여행은 보드에서 따로 붙일 수 있어요"가 보인다
- [ ] **3. 사진 올리기 → 베스트 고르기** (F1 ④⑤)
  - 확인: 사진을 고르면 진행 막대가 지나간 뒤, 장소별 묶음이 이름·장수와 함께 보인다
  - 확인: 위치 정보가 없는 사진은 "장소를 모르는 사진" 묶음에 모인다
  - 확인: 하나도 안 고르면 [다 골랐어요]가 흐리고 "마음에 드는 사진을 한 장 이상 골라 주세요"가 보인다
  - 확인: 고르다가 보드로 나가면 "고르는 중" 마그넷이 있고, 누르면 이어서 고를 수 있다
- [ ] **4. 첫 마그넷 → 여행 상세** (F1 ⑥⑦)
  - 확인: [다 골랐어요]를 누르면 보드에 처음 고른 사진과 도시 이름이 든 마그넷이 붙고 "완성! 첫 마그넷이 붙었어요"가 보인다
  - 확인: 마그넷을 누르면 위에 경로 지도, 아래에 고른 사진만 3열 그리드로 보인다
  - 확인: 위치 정보가 없는 사진만 고르면 지도 자리에 "사진에 위치 정보가 없어서 경로는 그리지 못했어요"가 보인다
