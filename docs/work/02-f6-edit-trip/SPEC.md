# 02 · F6 여행 고치기

> Vibe Studio · build-spec · 작성일: 2026-10-16
> 목표: UI 구현 · 관련 플로우: F6 · 조각 3개
> 정해둔 것: ../SETUP.md

- [x] **1. 고치기 메뉴 + 여행 지우기** (F6 ①②⑥)
  - 확인: 여행 상세의 `⋯`를 누르면 "사진 다시 고르기", "여행 정보 고치기", "여행 지우기"가 아래에서 올라온다
  - 확인: [여행 지우기] → "이 여행을 지울까요? 고른 사진도 함께 사라져요."가 보이고, [지우기]를 누르면 보드에서 그 마그넷이 사라진다
  - 확인: [그대로 두기]를 누르면 여행 상세가 그대로 있다
- [ ] **2. 여행 정보 고치기** (F6 ⑤)
  - 확인: [여행 정보 고치기]를 누르면 지금 도시·날짜가 채워진 화면이 나오고, 도시를 바꿔 [저장하기]하면 여행 상세 제목과 마그넷 이름이 바뀐다
  - 확인: 도시를 비우고 [저장하기]하면 "어디로 다녀왔는지 알려 주세요"가 보인다
- [ ] **3. 사진 다시 고르기 · 더 올리기 · 베스트에서 빼기** (F6 ③④, ① 크게 보기)
  - 확인: [사진 다시 고르기]를 누르면 고른 사진이 체크된 채로 열리고, 바꿔서 [다 골랐어요]하면 여행 상세 그리드에 바뀐 사진이 보인다
  - 확인: [사진 더 올리기]로 올린 사진이 묶음에 더해진다
  - 확인: 크게 보기에서 [베스트에서 빼기]를 누르면 그리드에서 그 사진이 사라지고, 한 장만 남으면 "마그넷엔 사진이 한 장은 있어야 해요"가 보인다
