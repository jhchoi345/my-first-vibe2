- **스택:** 프로토타입(설치 없는 브라우저 방식) — React + Tailwind CSS를 인터넷(CDN)에서 바로 불러옴, 빌드 도구 없음 · 화면 코드는 JavaScript + htm(JSX 대신 쓰는 문법) · 아이콘 Phosphor(`@phosphor-icons/react`) · 글꼴 Pretendard · 로컬 서버는 `.claude/serve-app.ps1`(포트 5173)
  - 이유: 이 컴퓨터에 Node.js가 없고 설치 없이 바로 만들어 보고 싶음. F1에 비밀 키가 필요한 기능이 없어 프로토타입으로 충분함
  - 나중에 Node.js를 설치하면 Vite 또는 Next.js로 옮길 수 있음(화면 코드는 대부분 그대로)
- **데이터:** 처음엔 빈 보드. 사용자가 올린 사진과 만든 여행을 브라우저에 저장(새로고침해도 남게). 사진은 용량이 커서 브라우저의 큰 저장 공간(IndexedDB)에 둔다. 진짜 저장소는 나중에
- **진짜로 하는 것:** 사진 파일 안의 위치·찍은 시간 읽기, 위치·시간으로 장소별 묶기
- **흉내만 낼 것:**
  - 로그인(카카오·구글) — 버튼만 누르면 바로 통과, 로그인 상태가 유지됨
  - 지도 — 지도 모양 그림 위에 사진 위치를 점과 선으로
  - 장소 이름 — 미리 넣어 둔 장소 목록에서 가장 가까운 이름, 없으면 도시 이름
  - 국내·해외 마그넷 — 미리 넣어 둔 도시 목록으로 나눔
- **이번엔 안 함:** 진짜 카카오·구글 로그인, 진짜 지도, 서버 저장, 사진 생김새로 비슷한 사진 묶기, 대표 사진 바꾸기, 실물 마그넷 사진으로 바꾸기, 동영상 올리기, 200장 넘게 올리기, 마그넷 꾸미기, 사진 안심 보관, 추억 다시 꺼내기 알림
- **옮길 때 다시 볼 것** (Next.js로 옮기면 서버로 가야 하는 것): 로그인, 여행·사진 저장
