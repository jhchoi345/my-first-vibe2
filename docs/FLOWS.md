## 앱 틀 (모든 화면 공통)
```
┌─────────────────────────┐
  모먼트립                       ← 흰 헤더 바 + 아래 구분선, 위에 고정
├─────────────────────────┤
  ┌─────────────────────┐
  │ (최근 여행 대표 사진)    │   ← 보드에서만: 대표 사진 배너
  │ 오사카 여행 잘 다녀왔어요? │
  └─────────────────────┘
  [마그넷] [마그넷] [ + ]
├─────────────────────────┤
  보드   지도   사진   내 계정     ← 아래 탭바, 아래에 고정
└─────────────────────────┘
```
- **위 헤더:** 흰 바탕, 아래 얇은 구분선. 탭 화면에선 로고 "모먼트립", 안쪽 화면에선 ← 뒤로 + 화면 제목(+ 오른쪽 버튼)
- **아래 탭바:** 보드 · 지도 · 사진 · 내 계정. 탭 화면(보드·지도·사진·내 계정)에서만 보이고, 안쪽 화면(여행 만들기·사진 올리기·베스트 고르기·여행 상세·여행 정보 고치기)에선 숨김 — 하던 일에 집중하게. 고른 탭은 주요 색
- **지도·사진 탭:** F5 전까지 "곧 만나요" 안내만. 문구: "다녀온 곳을 지도에서 다시 떠나 볼 수 있게 준비하고 있어요" · "모든 여행의 베스트 사진을 한곳에 모아 볼 수 있게 준비하고 있어요" (임시)
- **내 계정:** "○○로 로그인했어요", "로그아웃해도 이 기기에 모은 마그넷은 그대로 있어요." (임시), [로그아웃]
- **보드 대표 사진 배너:** 마그넷이 붙은 여행이 있을 때만, 가장 최근에 붙인 여행의 대표 사진을 보드 맨 위에 크게. 사진 위에 "{도시} 여행 잘 다녀왔어요?" · "그 순간들, 다시 꺼내 볼까요?" 누르면 그 여행 상세로. 빈 보드(F1 ②)엔 없음
- 변경 기록: 2026-10-16 F1·F6을 써 보고 "헤더 구분이 없고 기능으로 가는 길이 없다", "보드 위가 허전하다"는 의견으로 추가

## F1 · 첫 마그넷 붙이기 — "갤러리에 묻힌 그 여행 사진, 여기에 모아 볼까?"
> 구분: 첫 방문 · 상태: 기획 완료 · 담당 기능: 여행 만들기(지난 여행), 베스트 사진 고르기, 사진 그리드(여행별), 마그넷 보드(첫 마그넷)

**목표 순간**
- 진입 동기: 지인 링크나 소개 페이지로 처음 들어옴. 갤러리에 묻힌 지난 여행 사진이 떠오른 상태
- 목표 순간: 내가 고른 베스트 사진으로 첫 마그넷이 보드에 톡 붙고, 열어 보면 베스트 그리드와 경로가 보임
- 상태 변화: 빈 보드 → 마그넷 1개 (모름 → 써 봄)

**단계**
| 단계 | 화면 | 기능 | 주 행동 (→ 다음) | 핵심 결정 |
|:--:|------|------|------------------|-----------|
| ① | 시작 | — | [카카오로 시작하기] → ② | 로그인은 처음에 받음. 버튼 위에 마그넷 보드 미리보기 그림 — 로그인 전에 무엇을 하는 곳인지 보여 주려고 |
| ② | 마그넷 보드 | 마그넷 보드 | [여행 붙이기] → ③ | 빈 보드에 점선 마그넷 칸 하나, 버튼은 하나만 |
| ③ | 여행 만들기 | 여행 만들기(지난 여행) | 도시·날짜 입력 → [사진 올리기] → ④ | 첫 방문엔 지난 여행만. 도시·날짜만 받고 예산·가고 싶은 곳은 숨김 |
| ④ | 사진 올리기 | 베스트 사진 고르기 | 사진 선택 → 자동으로 묶기 → ⑤ | 올라가는 동안 묶는 중이라는 진행 표시 |
| ⑤ | 베스트 고르기 | 베스트 사진 고르기 | 묶음마다 사진 탭 → [다 골랐어요] → ⑥ | 미리 골라 두지 않음. 묶음마다 몇 장이든 자유롭게, 안 골라도 됨. 전체 최소 1장 |
| ⑥ | 마그넷 보드 | 마그넷 보드 | 마그넷이 붙는 애니메이션 → 마그넷 탭 → ⑦ | 대표 사진은 처음 고른 베스트로 자동, 국내·해외 템플릿은 도시로 자동 |
| ⑦ | 여행 상세 | 사진 그리드(여행별) | (목표 순간) 사진 탭 → 크게 보기 | 위에 작은 경로 지도, 아래 바둑판 그리드 |

**화면**

### ① 시작
```
┌───────────────────┐
  [마그넷 보드 그림]

  다녀온 여행의 순간들,
  여기에 하나씩
  모아 볼까요?

  [카카오로 시작하기]
  [구글로 시작하기]
  시작하면 약관·개인정보
  처리에 동의하게 돼요
└───────────────────┘
```
- **역할:** 무엇을 하는 곳인지 한눈에 보고, 부담 없이 시작한다
- **핵심 요소:** 화면 위쪽 절반에 마그넷 몇 개가 붙은 보드 미리보기 그림. 그 아래 큰 문구, 맨 아래에 카카오·구글 버튼이 세로로 두 개, 그 밑에 작은 글씨로 약관 동의 한 줄
- **문구:** "다녀온 여행의 순간들, 여기에 하나씩 모아 볼까요?" · "시작하면 약관·개인정보 처리에 동의하게 돼요" (임시)
- **상태:**
  - 로딩: 누른 버튼 안에 작은 회전 표시
  - 오류: 로그인 실패 — "로그인하지 못했어요. 다시 시도해 볼까요?" (임시)

### ② 마그넷 보드 (빈 보드)
```
┌───────────────────┐
  내 마그넷 보드

     ┌ ─ ─ ┐
       +
     └ ─ ─ ┘

  아직 마그넷이 없네요.
  첫 여행을 붙여 볼까요?
  지난 여행도 좋아요 🧳

  [여행 붙이기]
└───────────────────┘
```
- **역할:** 빈 보드에서 첫 여행을 붙일 곳이 어디인지 바로 보인다
- **핵심 요소:** 제목 "내 마그넷 보드", 가운데 점선 테두리의 빈 마그넷 칸 하나(+ 표시), 그 아래 안내 문구, 주요 버튼 하나
- **문구:** "아직 마그넷이 없네요. 첫 여행을 붙여 볼까요? 지난 여행도 좋아요 🧳"
- **상태:**
  - 빈: 이 화면 자체가 빈 상태
  - 로딩: 마그넷 자리에 옅은 칸
  - 오류: "보드를 불러오지 못했어요. 잠시 후 다시 열어 볼까요?" (임시)

### ③ 여행 만들기
```
┌───────────────────┐
  ←  지난 여행 붙이기

  어디로 다녀왔어요?
  [ 오사카          ] + 도시 더하기

  언제 다녀왔어요?
  [ 2026.9.12 – 9.15 ]

  [사진 올리기]
└───────────────────┘
```
- **역할:** 여행 하나를 가볍게 정한다
- **핵심 요소:** 도시 입력(여러 개 더할 수 있음), 날짜 범위 입력, 맨 아래 주요 버튼. 예산·가고 싶은 곳 칸은 없음
- **문구:** "지난 여행 붙이기" (임시) · "어디로 다녀왔어요?" (임시) · "언제 다녀왔어요?" (임시)
- **상태:**
  - 오류: 도시가 비어 있음 — "어디로 다녀왔는지 알려 주세요" (임시)

### ④ 사진 올리기
```
┌───────────────────┐
  오사카 · 2026.9.12–15

   ▢ ▢ ▢ ▢
   ▢ ▢ ▢ ▢

  ████████░░░░  64%
  같은 곳에서 찍은 사진끼리
  모으는 중이에요
└───────────────────┘
```
- **역할:** 고른 사진이 올라가며 묶이는 걸 기다린다
- **핵심 요소:** 위에 여행 이름, 가운데 올라가는 사진 썸네일 격자, 아래 진행 막대와 안내 문구. 사진 고르기는 브라우저 사진 선택창
- **문구:** "같은 곳에서 찍은 사진끼리 모으는 중이에요" (임시)
- **상태:**
  - 로딩: 진행 막대 + 위 문구
  - 오류: "사진을 불러오지 못했어요. 잠시 후 다시 올려 볼까요?"

### ⑤ 베스트 고르기
```
┌───────────────────┐
  같은 곳에서 찍은 사진끼리
  모아 뒀어요. 마음에 드는
  사진을 골라 주세요.

  📍 도톤보리  (12장)
  ▢ ▣ ▢ ▢ →
  📍 오사카성   (8장)
  ▢ ▢ ▢ ▣ →
  📍 장소를 모르는 사진 (3장)
  ▢ ▢ ▢

  [다 골랐어요 · 5장]
└───────────────────┘
```
- **역할:** 묶음마다 마음에 드는 사진만 고른다
- **핵심 요소:** 위에 안내 문구, 장소 묶음마다 장소 이름·장수 한 줄과 그 아래 가로로 이어지는 사진 줄(옆으로 넘김). 고른 사진은 체크 표시. 맨 아래에 고른 장수가 붙은 주요 버튼이 고정
- **문구:** "같은 곳에서 찍은 사진끼리 모아 뒀어요. 마음에 드는 사진을 골라 주세요." · "다 골랐어요 · N장" (임시)
- **상태:**
  - 빈: 하나도 안 고름 — 버튼이 흐리게 + "마음에 드는 사진을 한 장 이상 골라 주세요" (임시)

### ⑥ 마그넷 보드 (첫 마그넷)
```
┌───────────────────┐
  내 마그넷 보드
   ┌────┐
   │사진│ ← 톡!
   │오사카│
   └────┘  ┌ ┐
           └ ┘ +
  완성! 첫 마그넷이
  붙었어요
└───────────────────┘
```
- **역할:** 내가 고른 사진으로 첫 마그넷이 붙는 걸 본다 (목표 순간의 시작)
- **핵심 요소:** 대표 사진과 도시 이름이 들어간 마그넷이 보드에 톡 붙는 움직임. 옆에 다음 여행을 붙일 점선 빈 칸. 아래 짧은 축하 문구
- **문구:** "완성! 첫 마그넷이 붙었어요" (임시)
- **상태:**
  - 로딩: 마그넷을 만드는 동안 빈 칸이 살짝 깜빡임
  - 오류: "마그넷을 붙이지 못했어요. 다시 시도해 볼까요?" (임시)

### ⑦ 여행 상세
```
┌───────────────────┐
  ←  오사카 · 2026.9.12–15
  ┌─────────────────┐
  │ 지도 ●─●──●      │
  └─────────────────┘
  ▢ ▢ ▢
  ▢ ▢ ▢
  ▢ ▢
└───────────────────┘
```
- **역할:** 내가 고른 베스트 사진과 경로를 한눈에 본다 (목표 순간)
- **핵심 요소:** 위에 여행 이름·날짜, 그 아래 작은 지도에 사진 위치를 잇는 경로 선과 점, 아래 3열 바둑판 사진 그리드. 사진을 누르면 크게 보며 장소가 같이 나옴
- **문구:** "오사카 · 2026.9.12–15"
- **상태:**
  - 빈: 위치 정보가 하나도 없음 — 지도 자리에 "사진에 위치 정보가 없어서 경로는 그리지 못했어요" (임시), 그리드는 그대로
  - 로딩: 그리드 자리에 옅은 칸

**예외**
| 단계 | 상황 | 어떻게 동작하나 |
|:--:|------|----------------|
| ① | 로그인 창을 닫음 | 시작 화면 그대로 |
| ③ | 앞으로의 날짜를 넣음 | "아직 안 간 여행은 보드에서 따로 붙일 수 있어요" (임시) 안내 |
| ④ | 사진 선택을 취소 | ③으로 돌아가고 입력은 그대로 |
| ④ | 동영상이나 못 읽는 파일 | 건너뛰고 "사진만 올렸어요" (임시) |
| ④·⑤ | 올리다가·고르다가 나감 | 보드에 "고르는 중" 마그넷으로 남고, 탭하면 이어서 |
| ⑤ | 위치 정보가 없는 사진 | "장소를 모르는 사진" 묶음 하나로 따로 모음 |
| 전체 | 로그인이 풀림 | 다시 로그인하면 보던 화면으로 |

**첫 버전 범위**
- 넣음: 카카오·구글 로그인, 지난 여행 만들기(도시·날짜), 사진 올리기, 장소·찍은 시간으로 묶기, 베스트 고르기, 마그넷 자동 생성(국내·해외 기본 템플릿), 여행 상세(경로 지도 + 그리드 + 크게 보기)
- 나중에: 사진 생김새까지 보고 비슷한 사진 묶기, 대표 사진 바꾸기, 실물 마그넷 사진으로 바꾸기, 동영상 올리기, 한 번에 올리는 장수 제한 늘리기(첫 버전 200장 (임시))

**건너뛴 기본값:** 여행 하나에 도시 여러 개 가능, 마그넷 이름은 첫 도시 · 마그넷 대표 사진은 처음 고른 베스트로 자동 · 국내·해외 템플릿은 도시로 자동 · 크게 보기에는 장소만(한 줄 기록은 F2부터)

## F6 · 여행 고치기 — "앗, 사진 잘못 올렸네. 바꾸고 싶다"
> 구분: 기능 · 상태: 기획 완료 · 담당 기능: 베스트 사진 고르기(다시 고르기), 사진 그리드(여행별), 마그넷 보드

**목표 순간**
- 진입 동기: 여행 상세를 보다가 잘못 고른 사진, 빠뜨린 사진, 틀린 도시·날짜가 눈에 띔. 또는 테스트로 만든 여행을 치우고 싶음
- 목표 순간: 고친 사진·정보가 여행 상세와 마그넷에 바로 보이거나, 지운 여행이 보드에서 사라짐
- 상태 변화: 마음에 안 드는 여행 → 내 마음에 맞는 여행

**단계**
| 단계 | 화면 | 기능 | 주 행동 (→ 다음) | 핵심 결정 |
|:--:|------|------|------------------|-----------|
| ① | 여행 상세 | 사진 그리드(여행별) | 오른쪽 위 `⋯` 탭 → ② / 사진 탭 → 크게 보기에서 [베스트에서 빼기] | 고치는 길은 `⋯` 하나로 모음. 사진 한 장 빼기만 크게 보기에서 바로 |
| ② | 고치기 메뉴 | — | 사진 다시 고르기 → ③ / 여행 정보 고치기 → ⑤ / 여행 지우기 → ⑥ | 아래에서 올라오는 메뉴. 세 개만 |
| ③ | 베스트 고르기 | 베스트 사진 고르기(다시 고르기) | 사진을 빼고 더하고 [다 골랐어요] → ① / [사진 더 올리기] → ④ | 고른 사진이 체크된 채로 열림 |
| ④ | 사진 올리기 | 베스트 사진 고르기 | 사진 선택 → 묶음에 더해짐 → ③ | 새 사진은 기존 사진과 함께 다시 장소별로 묶음. 고른 건 그대로 |
| ⑤ | 여행 정보 고치기 | — | 도시·날짜 고치고 [저장하기] → ① | 여행 만들기 화면을 그대로 쓰되 지금 값이 채워진 채로 |
| ⑥ | 지우기 확인 | 마그넷 보드 | [지우기] → 보드 / [그대로 두기] → ① | 되돌릴 수 없어서 화면 안에서 한 번 더 물음 |

**화면**

### ① 여행 상세
- → F1 ⑦ 참고. 달라지는 점: 제목 줄 오른쪽 끝에 `⋯` 버튼. 크게 보기 아래에 [베스트에서 빼기]
- **문구:** "베스트에서 빼기" (임시)
- **상태:**
  - 빈: 남은 베스트가 한 장 — [베스트에서 빼기]가 흐리고 "마그넷엔 사진이 한 장은 있어야 해요" (임시)

### ② 고치기 메뉴
```
┌───────────────────┐
  (여행 상세가 흐리게)
 ┌─────────────────┐
   사진 다시 고르기
   여행 정보 고치기
   여행 지우기
   [닫기]
 └─────────────────┘
└───────────────────┘
```
- **역할:** 무엇을 고칠지 고른다
- **핵심 요소:** 화면 아래에서 올라오는 흰 시트. 메뉴 세 줄이 세로로, 맨 아래 닫기. 바깥을 눌러도 닫힘
- **문구:** "사진 다시 고르기" · "여행 정보 고치기" · "여행 지우기" (임시)

### ③ 베스트 고르기
- → F1 ⑤ 참고. 달라지는 점: 고른 사진이 체크된 채로 열림. 안내 문구 아래에 [사진 더 올리기]. [다 골랐어요]를 누르면 보드 대신 여행 상세로 돌아감. 대표 사진은 처음 고른 사진(고른 순서의 첫 장)
- **문구:** "사진 더 올리기" (임시)

### ④ 사진 올리기
- → F1 ④ 참고. 달라지는 점: 다 올리면 새 사진이 기존 묶음에 더해진 베스트 고르기로 돌아감

### ⑤ 여행 정보 고치기
- → F1 ③ 참고. 달라지는 점: 제목 "여행 정보 고치기", 지금 도시·날짜가 채워져 있음, 버튼은 [저장하기]이고 사진 선택창이 열리지 않음
- **문구:** "여행 정보 고치기" · "저장하기" (임시)

### ⑥ 지우기 확인
```
┌───────────────────┐
 ┌─────────────────┐
   이 여행을 지울까요?
   고른 사진도 함께
   사라져요.
   [지우기]
   [그대로 두기]
 └─────────────────┘
└───────────────────┘
```
- **역할:** 실수로 지우지 않게 한 번 더 확인한다
- **핵심 요소:** ②와 같은 아래 시트. 문구 두 줄, 주요 버튼 [지우기], 그 아래 보조 버튼 [그대로 두기]
- **문구:** "이 여행을 지울까요? 고른 사진도 함께 사라져요." (임시)

**예외**
| 단계 | 상황 | 어떻게 동작하나 |
|:--:|------|----------------|
| ① | 남은 베스트가 한 장인데 빼려 함 | 버튼이 흐리고 안내 문구 |
| ③ | 다시 고르다 나감 | 지금까지 바꾼 선택은 남음(F1과 같음) |
| ③ | 대표 사진을 뺌 | 다음으로 고른 사진이 마그넷 대표가 됨 |
| ④ | 사진 선택을 취소 | ③ 그대로 |
| ⑤ | 도시를 비우거나 앞으로의 날짜를 넣음 | F1 ③과 같은 안내 |
| ⑥ | 마지막 여행을 지움 | 빈 보드(F1 ②)로 |
